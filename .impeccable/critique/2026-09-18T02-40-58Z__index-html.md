## Design Specificity Verdict

**Not specific — a theme shell, interchangeable with any developer portfolio.** Palette, numbered nav, offset-portrait frame, side rails, and the hero grammar are a line-for-line transplant of brittanychiang.com (acknowledged in the footer and README). The LRT card is the most credible content on the page, but the design does not yet believe it: zero visual artifacts of the craft (charts) on a portfolio whose whole pitch is "I turn data into dashboards."

Detector: 1 warning on index.html (`low-contrast` — unreproducible, likely false positive), resume/cover-letter clean. Deployed site (portfolio.diniemuzaffar.workers.dev) currently serves the OLD copy — the update is unshipped.

## Overall Impression

Competent, honest, well-engineered scaffolding wearing a borrowed, product-irrelevant skin. The writing is refreshingly scoped ("800+ real public posts", "never raw post text") and the accessibility scaffolding is senior-grade. The single biggest opportunity: make the page itself a sample of the craft it advertises.

## What's Working

1. **Honest, precisely-scoped copy** — the LRT card states observable numbers with zero hype; exactly the trait an AML/regulatory-data employer values most.
2. **Real accessibility engineering, done not pasted** — skip link, correct ARIA tabs with arrow-key support, reduced-motion gating.
3. **Serious cross-artifact system** — deploy-ready resume with print CSS + a live-updating cover-letter generator.

## Priority Issues

1. **[P0] Borrowed identity.** The composition is a clone of a top-20 front-end template; a design-literate evaluator will clock it and discount the candidate's design judgment before the first project. *Fix:* build a data-native identity (chart motifs, tabular grids) or at least an original frame; drop the sidebar rails + numbered nav. *Command:* `/impeccable bolder` / `/impeccable shape`.
2. **[P0] Zero evidence of the craft on the canvas of the craft.** Both flagship dashboards show as text monograms ("F1"/"LRT"). *Fix:* ship real Altair/matplotlib thumbnails generated by the repos' own pipelines, linking to the live apps. *Command:* `/impeccable overdrive`.
3. **[P1] LRT card external link mislabeled.** index.html:266-267 — the external-link icon has `aria-label="GitHub repo"` but points at the live Streamlit demo; screen readers hear "GitHub repo, GitHub repo" for two different destinations. *Fix:* one-line aria-label change ("Live dashboard"). *Command:* `/impeccable clarify`.
4. **[P1] Peak-zone density.** Nine MAHB bullets + ~350-word About + 16 tech items bury the 3M-rows/day and 90%-accuracy claims. *Fix:* trim About ~150 words; collapse MAHB to 4-6 bullets with metrics leading. *Command:* `/impeccable distill`.
5. **[P1] Mobile dead-end navigation.** `.nav-links` disappears under 768px with no replacement menu. *Fix:* hamburger/disclosure or a sticky section strip. *Command:* `/impeccable adapt`.

Process note (from Assessment B): the update currently sits uncommitted on `main`, and the deployed site is stale — per repo rules it must go on a feature branch + PR, then deploy. This is the pending git step of this work, not a design defect.

## Persona Red Flags

- **Hiring manager (fast evaluator):** About + MAHB slabs force a 60-second scan to surface "maps to my Data Engineer req", then there are no chart thumbnails to confirm it.
- **Sam (accessibility):** two "GitHub repo"-labeled links to different destinations; unstoppable cursor blink under `prefers-reduced-motion`; `aria-hidden` social rail whose links stay keyboard-focusable and unlabeled (index.html:439).
- **Casey (mobile):** no navigation under 768px; tiny 0.8rem experience-tab targets requiring horizontal scroll.

## Questions to Consider

1. If the footer hadn't named brittanychiang.com, would one person believe this composition is yours?
2. The portfolio claims "I turn data into dashboards" — and contains zero charts. What would the F1 and LRT thumbnails prove that the new LRT card's text can't?
3. In a 15-second glance, does "6 roles + 16 tech items + 2 aspirational titles" make a hiring manager feel focused or scattered?
4. The strongest story — a privacy-first-by-construction dashboard — sits in a subordinate clause of a project card. What if it were a hero moment?
